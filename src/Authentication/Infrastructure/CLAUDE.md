# Authentication/Infrastructure/

Adapters and framework glue. `Http/` controllers and DTOs, `Persistence/` Doctrine + in-memory repositories, `Crypto/` (Argon2id, XChaCha20-Poly1305, token hashing), `Jwt/`, `Mail/`, `Social/` (Google/Apple JWKS), `Totp/`, `Security/` (firewall classes), `RateLimit/`, `Console/`, `Messaging/`, `Scheduler/`. Wired in `config/services/authentication.yaml`.
