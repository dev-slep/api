# translations/

ICU message files, two locales: `en` and `sr_Latn` (Serbian Latin, default).

- `problems+intl-icu.<locale>.yaml`: titles and details of RFC 9457 problem responses, keyed by problem slug.
- `auth_mail+intl-icu.<locale>.yaml`: subject and body of the authentication emails.

Every key must exist in both locales. New problem types need an entry in both files.
